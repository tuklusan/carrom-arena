# Reference material

- `ICF-Carrom-Official-Rules.pdf` - the International Carrom Federation Laws of Carrom (rule numbers 1-143), as published at
  https://www.iakc.org/wp-content/uploads/2020/02/Carrom-Official-Rules.pdf (fetched 2026-09-26). The game implements these
  rules; code comments cite them as "ICF nn".
- `ICF-Carrom-Official-Rules.txt` - plain-text extract of the same PDF (pdftotext -layout), for searching.
